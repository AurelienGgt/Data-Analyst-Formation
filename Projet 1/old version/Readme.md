<h2 align="center"> 🎯 Project Objectives </h2>

> 🧠 *«Get hands-on with Python to analyze FAO data on global hunger.»*

- Explore data related to undernutrition (food parameters, health indicators).
- Clean the data: handle missing values, normalize, and remove anomalies if necessary.
- Analyze relationships between nutritional, demographic, and health variables.
- Identify key indicators to guide future analyses or modeling efforts.

---

<h2 align="center"> 🧰 Tools & Libraries </h2>

- Language: Python
- Software: Jupyter Notebook
- Analysis libraries: Pandas, NumPy
- Visualization libraries: Matplotlib, Seaborn

---

<h2 align="center"> 🔍 Main Steps </h2>

- Data loading + initial overview + formatting
- Diagnostics: data types, missing values, duplicates
- Handling anomalies, standardizing units
- Feature Engineering
- Univariate analysis: distributions, descriptive statistics
- Deeper exploratory analysis based on health/nutrition hypotheses required for the project
